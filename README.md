# 🌐 Personal Profile Web Page

> **DigiSkills 3.0 Batch-04 | Full Stack Development with MERN | Hands-on Exercise No. 1**

A fully responsive **Personal Profile Web Page** built with **HTML5 & CSS3** — featuring a modern dark theme, animated hero section, skills showcase, project cards with live demo links, and a contact section.

---

## 🔗 Live Preview

> Open `index.html` in any browser to view the profile page locally.

---


## 🚀 Features

- ✅ **Responsive Design** — Works on all screen sizes (mobile, tablet, desktop)
- 🎨 **Dark Theme** — Premium dark purple/pink gradient aesthetic
- ✨ **Animated Hero** — Glowing avatar with pulsing animation
- 💼 **Experience Timeline** — Internship history with status badges
- 💡 **Skills Showcase** — 6 skill categories with color-coded tags
- 🚀 **Project Cards** — 6 real projects with tech stack & demo links
- 🏆 **Certifications** — All achievements and certificates listed
- 📬 **Contact Section** — Email, LinkedIn, GitHub and location

## ⚙️ How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/NailaKhani/personal-profile.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd personal-profile
   ```

3. **Open `index.html` in your browser**
   - Simply double-click `index.html`, or
   - Right-click → **Open with** → Chrome / Edge / Firefox
